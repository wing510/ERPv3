# ERP 對話續接記憶

> 用途：當聊天記錄遺失時，直接把本檔內容貼給 AI，即可快速接續工作。  
> 更新方式：每次有「新決策 / 新進度 / 新阻塞」就補一行。

## 專案固定偏好
- 回覆語言：繁體中文
- 工作原則：可直接實作就先做，避免只停在規劃，除非我有說先討論
- 使用者規則：當使用者說「你記住」，AI 完成調整後需同步寫入本文件
- API 端點規則：
  - 使用者貼 `/exec` 網址且明確說「開發」→ 更新 `API_BASE_DEV`
  - 使用者貼 `/exec` 網址且明確說「正式」→ 更新 `API_BASE_PROD`
  - 若未明確指定環境，需先詢問，不可直接改 `defaults.API_BASE`
- 教學模式：使用「新手模式」（使用者非工程師）
  - 先講結論再講原因
  - 一次只給 1 個小步驟（最多 3 個動作）
  - 少術語，必要時翻成白話
  - 每步都要有「成功判斷」提示
  - 需要回報時提供可直接複製的填空模板
  - AI 負責技術判斷，使用者只需回報看到的現象
